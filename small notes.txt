Make sure that, in the future, when you are creating a new react app that you install any libraries you need with npm.
For example its not enough to just import bootstrap. You need to actually install it using npm install bootstrap and npm
install react bootstrap. This then puts those in your package.json, so that when you run npm install by itself on a new
computer, it automatically installs it for you. This is why you didnt need to do this for your hws, it was all taken care
of by npm install.
Also need to do it for stuff like react router.
